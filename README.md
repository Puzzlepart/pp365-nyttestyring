# Nyttestyring i Prosjektportalen 365

Løsningsforslag og klikkbar prototype for en ny nyttestyringsmodul (gevinstmodul) i
[Prosjektportalen 365](https://github.com/Puzzlepart/prosjektportalen365). Modellen følger DFØs veileder
om nyttestyring.

- **Prototype:** https://puzzlepart.github.io/pp365-nyttestyring/
- **Løsningsforslag:** [losningsforslag.md](losningsforslag.md)
- **Plan for prototypen:** [prototype-plan.md](prototype-plan.md)

Prototypen er én selvstendig HTML-fil uten eksterne avhengigheter. Alle data er fiktive (Fjordvik kommune).
Endringer du gjør i prototypen lagres bare i din egen nettleser. «Tilbakestill demodata» øverst til høyre
setter alt tilbake.

Dette er et arbeidsdokument. Når modulen implementeres, flyttes den endelige versjonen av
løsningsforslaget inn i prosjektportalen365.
